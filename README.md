# 深大羽毛球预约助手

一个面向深圳大学体育场馆预约系统的 **Windows 桌面工具**，使用 WPF、WebView2 和学校页面当前会话完成羽毛球场查询与预约。支持保存多个本校账号、自动登录、双时段抢场、场号优先级、次日监测以及 12:29 一次性放场计划。

> 本项目是非官方的个人工具，与深圳大学无关。请仅使用本人账号，并遵守学校场馆预约规则、使用限制及相关管理规定。学校页面或接口变化可能导致功能失效。

## 功能一览

- **校园账号管理**：保存多个学号账号，选择账号后自动登录并进入羽毛球预约页。
- **本机密码保护**：密码使用 Windows DPAPI 的当前用户作用域加密，不同 Windows 用户不能直接复用加密密码。
- **双时段预约**：最多同时设置两个候选时段；一个时段成功后只停止该时段，另一个时段继续执行。
- **实时查询与提交**：每轮通过学校接口重新获取可订场地，筛选后提交，不依赖静态余量数据。
- **场地偏好**：可选择场馆大类或学校接口返回的具体场号；偏好不可用时继续等待，不自动跨偏好预约。
- **场号优先级**：粤海按 D→C→B→A、同区数字升序；丽湖按场号数字倒序。
- **次日监测**：可提前设置目标日期、时段与场地偏好，手动开始监测。
- **12:29 一次性计划**：在放场前 1 分钟开始监测与抢场，适用于次日 12:30 放出的目标日期。
- **代理进程控制**：可选启动、停止用户自行配置的本地代理程序，并设置浏览器代理。
- **中文桌面界面**：集成学校预约页面、预约设置、执行状态与日志。

## 放场与日期规则

程序按以下业务规则生成目标日期，不再抓取页面中的日期列表来推断规则：

| 当前时间 | 可选择的目标日期 |
| --- | --- |
| 00:00–22:00 | 当天、后一天 |
| 22:00–24:00 | 后一天、后两天 |

- 每天 12:30 放出后一天的场地，12:29 计划会提前 1 分钟开始监测。
- 当天场次在 22:00 后结束，因此晚间日期范围自动向后移动。
- 计划是一次性任务；修改设置后如需再次执行，请重新设置计划。
- 自动计划运行时，应用必须保持打开，电脑应保持唤醒且网络可用。

## 场号选择顺序

每轮执行时，程序先过滤学校接口返回的不可用场地，再应用场地偏好，最后按校区优先级选择当前第一个可订场地：

1. **粤海校区**：D1、D2……D7，然后依次选择 C 区、B 区、A 区，各区按数字升序。
2. **丽湖校区**：10 号场、9 号场……1 号场。
3. 能识别场号的场地排在无法识别名称的场地之前。
4. 场号列表由学校接口动态返回，程序不写死完整场地清单；学校新增编号也会按数字规则参与排序。
5. 如果选择“至畅”“至快”或其他具体偏好，只在该偏好范围内排序和提交。

若查询无可用场地、场地已被他人抢走或提交失败，程序会按设置的间隔重试，直到该时段成功、全部时段完成或用户手动停止。

## 使用步骤

1. 启动应用，在“校园账号”区域输入本人学号和密码并保存。
2. 选择已保存账号，点击“自动登录并进入”；首次使用如遇学校额外验证，请在应用内页面完成。
3. 选择校区、目标日期、首选时段，可按需启用第二候选时段。
4. 打开场地偏好下拉框，可读取学校当前返回的真实场号；也可选择场馆大类。
5. 设置重试间隔，然后选择一种执行方式：
   - **立即抢场**：立即查询并提交当前目标日期。
   - **开始次日监测**：持续监测尚未开放或暂时无场的目标日期。
   - **12:29 计划**：保存一次性计划，到点自动开始。
6. 在状态区域查看当前进度。需要中止时点击“停止”。

> 请先在非高峰时段核对校区、日期、时段和偏好。最终预约结果以学校系统“我的预约”为准。

## 账号安全与隐私

- 应用设置保存在当前 Windows 用户的 `%LOCALAPPDATA%\SzuBadminton\settings.json`，**不在源码目录中**。
- 学号作为本机账号标识保存；密码不以明文写入设置文件，而是通过 DPAPI 加密。
- DPAPI 用于本机保护，并不等同于防止已控制当前 Windows 账户的攻击者读取密码。
- 除登录和预约所必需的深圳大学系统外，本项目不会把账号信息主动同步到 GitHub 或其他第三方云端服务。
- 仓库不收录本机设置、真实账号截图、学校响应调试文件、日志或浏览器数据。
- 公共计算机上不建议保存密码；不再使用时，请删除应用内账号及上述本地设置文件。
- 代理程序及其配置由用户自行提供。使用第三方代理前，请自行评估校园账号的凭据安全风险。

**贡献代码前请再次确认：不要提交真实学号、密码、加密后的本机密码、`settings.json`、Cookie、会话令牌或含个人信息的截图。**

## 运行环境

### 直接运行发布版

- Windows 10/11 x64
- Microsoft Edge WebView2 Runtime（多数 Windows 设备已预装）
- 自包含单文件版本无需另外安装 .NET Runtime

### 从源码构建

- Windows 10/11
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- Microsoft Edge WebView2 Runtime

## 从源码运行

```bash
git clone https://github.com/Dioinnet/SZU-badmintonCourt.git
cd SZU-badmintonCourt
dotnet restore src/SzuBadminton/SzuBadminton.csproj
dotnet run --project src/SzuBadminton/SzuBadminton.csproj -c Release
```

## 构建 Windows 单文件版本

```bash
dotnet publish src/SzuBadminton/SzuBadminton.csproj `
  -c Release `
  -r win-x64 `
  --self-contained true `
  -p:PublishSingleFile=true `
  -p:IncludeNativeLibrariesForSelfExtract=true `
  -p:DebugType=None `
  -o artifacts/win-x64
```

PowerShell 使用反引号换行；在 CMD 中可将命令写为一行，或将反引号替换为 `^`。输出文件为 `artifacts/win-x64/SzuBadminton.exe`，该目录已被 Git 忽略。

## 运行测试

```bash
dotnet test tests/SzuBadminton.Tests/SzuBadminton.Tests.csproj -c Release
```

测试覆盖凭据加密往返、设置序列化、放场与日期边界、一次性计划时间窗、时段独立完成状态、学校响应解析、场地偏好和代理进程等逻辑。

## 技术实现

- **UI**：WPF / XAML
- **内嵌页面**：Microsoft.Web.WebView2
- **目标框架**：`.NET 8 (net8.0-windows)`

## 常见问题

### 启动后页面空白或提示 WebView2 不可用

安装或修复 Microsoft Edge WebView2 Runtime 后重新启动应用。

### 提示登录失效或学校接口返回 401

在学校页面重新登录，然后再开始监测或抢场。长时间等待时，校园会话可能过期。

### 已显示有场但没有预约成功

余量可能在查询后、提交前被其他用户抢走，也可能被学校规则拒绝。程序会保留学校返回的错误并继续重试；最终结果以学校系统为准。

### 到时间没有执行计划

确认应用仍在运行、电脑未睡眠、网络正常，并检查一次性计划是否仍在有效期内。程序提供有限的补执行时间窗，不支持关机后补跑。

### 为什么换 Windows 用户后无法解密密码

这是 DPAPI 当前用户保护的正常行为。请在新 Windows 用户下重新保存账号密码。
